# Wakfudle

A fan-made guessing game built around the world of Wakfu.

## How to Play

1. Download the latest release from [Releases](https://github.com/Winterlapse/wakfudle-game/releases)
2. Extract the `.zip` file — contains the game executable and the `data` folder, which is essential for the game's functionality
3. Run `Wakfudle.exe` — the executable must be in the same folder as the `data` to work

## Gamemodes

- **Wakguessr** — Guess the subregion of the World of Twelve based on an in-game screenshot
- **Monster Guesser** *(Coming Soon)* — Guess the name of a monster based on its image
- **Item Guesser** *(Coming Soon)* — Guess the name of an item based on its image

## Gameplay Modes

- **Standard** — 10 rounds, 30 seconds per round
- **Against The Clock** — 15 rounds, 60 seconds total
- **Endless** — Infinite rounds, no timer
